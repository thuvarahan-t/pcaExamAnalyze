# Offer feedback and PCA Exam PWA

Work starts on `feat/offer-package-admin-purchase-feed` at `41dca5a`. The existing untracked seminar photos and Offer progress notes are outside this change. The implementation uses the current Offer moderation workflow, Spring Security, R2 image client, and student exam routes.

Offer voice typing uses Gemini first in the adult-only deployment. Set `GEMINI_API_KEY` and `PCA_FEEDBACK_VOICE_ENABLED=true` to enable it. The default is `gemini-3.5-flash-lite`, with `GEMINI_MODEL` available to select another compatible model. Set `GROQ_API_KEY` to enable Groq as the backup for Gemini quota, temporary service, or connection errors. `GROQ_MODEL` defaults to `whisper-large-v3`. Completed checks for Groq as primary and Gemini text cleanup document the earlier implementation.
