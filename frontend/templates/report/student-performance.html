How to use the analysis

  1. Start with the lowest-accuracy subjects and check how many questions support each figure.
  2. Use the competency and content breakdowns to narrow down which material to revise.
  3. Use the question appendix to distinguish wrong answers from questions you left blank.
  4. Free marks count toward exam marks, but do not count as evidence of subject mastery.

Subject / unit performance

Lowest accuracy first. Weak = below 50%, Needs practice = 50-74%, Strong = 75% and above. Accuracy = correct answers divided by all assessed questions in that area, including unanswered questions.

A question can carry several tags. It counts once in each applicable area. Area totals can therefore overlap and must not be added together. Subjects with fewer than 3 questions are marked as limited evidence.
